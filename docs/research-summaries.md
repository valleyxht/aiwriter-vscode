# 资料目录与章节摘要

在侧边栏顶部的「创作工具 → 资料目录与章节摘要」操作，也可执行命令「AI Writer: 资料目录与章节摘要」。

1. 点击「配置忽略规则」，编辑工作区根目录的 `.aiwriterignore` 并保存。
2. 点击「查看目录与摘要」核对收录范围；此操作只同步本地目录，不调用模型。
3. 点击「生成 / 更新摘要」，使用当前 AI 配置生成新增、已修改或上次失败的章节摘要。
4. 需要覆盖全部生成内容时，点击「全部重新生成」。进度通知或工具面板均可取消；已完成内容保留，下次增量更新继续。

## 范围规则

默认收录工作区内 `.md` / `.txt` 文件。`.aiwriterignore` 使用 Git ignore 语法，支持注释、目录、通配符和 `!` 例外。它独立于 `.gitignore`，当前只控制摘要目录，不改变已有 RAG 和文件工具的范围。

```gitignore
# 不收录废稿目录和私人笔记
废稿/
**/私人笔记.md

# 同目录中保留指定文件
临时*.md
!临时设定.md
```

只收录「小说」目录可以写：

```gitignore
/*
!/小说/
```

与 Git 一样，被排除的父目录需要先用 `!` 恢复才能收录其中的文件。`.git`、`.aiwriter`、`node_modules`、`.vscode` 以及符号链接始终不参与生成。多根工作区会先选择具体根目录，每个根维护自己的配置。

## 生成和更新

- 识别「第 X 章 / 回 / 节 / 卷 / 篇」、英文 Chapter 和 Markdown 一级至三级标题；无标题文件作为一份完整资料。没有明确标题的长文件会完整分段摘要，不能自动推断隐含章节。
- 每段生成一句目录说明和 Markdown 摘要，保留事件因果、人物变化、时间地点和伏笔；普通资料保留规则、事实与顺序。
- 长章节分段生成后合并，不静默截断原文。过程串行，可查看当前章节、分段和模型返回的 Token 用量。
- 文件新增、删除、移动和保存会在目录已建立后触发本地同步；保存忽略规则也会同步。监听不调用模型，重启及手动操作会补做扫描。
- 使用内容哈希识别变化；前一章变长导致后续位置移动时，后续摘要可以复用。新章节为待生成，变化章节为过期。
- 目录刷新仍核对文件清单与元数据，但未变化的文件不再读取正文、解析章节或重新计算哈希；依据大小、修改/状态变更时间、文件标识及编辑器版本复用缓存。文件事件会使对应路径及其子目录失效，未保存文档显示待保存错误，不复用为最新结果。
- 「重新核对原文」跳过缓存检查全部正文，不调用模型；「全部重新生成」也会先核对全文。无变化时不重写目录。旧目录缺少缓存字段会自动读取一次并补齐。
- 生成失败保留旧摘要并显示错误；生成中原文改变时不保存已过期结果。鉴权、配额或模型不可用错误会停止本次批处理，避免对每章重复失败调用。
- 全部结果都是可再生成的数据，完整重建可以覆盖人工编辑。仅处理已保存正文，复用现有编码读取机制。

## 数据与代码

工作区 `.aiwriter/research/catalog.json` 保存文件、章节标题、字符范围、内容哈希、目录说明和摘要路径；正文摘要在同目录的 `summaries/`。已被目录替换或移除的生成摘要会清理，不保留稿件备份。

实现集中在 `src/memory/research/`：

- `catalog.ts`：ignore 匹配、扫描、章节映射、哈希及持久化。
- `summarizer.ts`：模型调用、分段合并、增量生成、取消和逐章保存。
- `controller.ts`：创作工具入口、工作区监听、进度与状态。
- `types.ts`：目录结构及状态。
- `prompts.json`：生成与合并提示词。

模型调用复用厂商适配、重试/并发策略及 LangSmith，追踪操作名为 `research_summary`。

资料检索 Agent 通过 `navigation.ts` 接入按需加载：初始只注入简短文件目录，`listResearchCatalog` 分页查看章节，`readChapterSummary` 读取所选摘要，必要时继续使用 `readFile` 读取原文。目录放在项目记忆之后、用户提供的上下文之前，不传入主 Agent 或其他专业 Agent。明确关键词仍可直接搜索，不强制增加调用链。

摘要与原文证据分开标注。读取摘要时本地读取当前源文件核对哈希，不将全文发送给模型；原文变动后停止提供旧字符范围。按目录位置读取正文时携带 `expectedSha256`，再次变动会要求重新定位。没有目录时原有检索正常使用，查询不会自动生成摘要。实际 Token 与时延收益仍需真实任务测量。
